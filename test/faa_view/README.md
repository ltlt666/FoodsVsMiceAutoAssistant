# FAA视角验证

```powershell
uv run python -m unittest test.faa_view.test_faa_view -v
```

测试使用离屏 Qt 和模拟客户区，不获取或操作真实游戏窗口。覆盖静默与开关、玩家隔离、DPI 点击投递、
NumPy 切片来源、单模板/多模板/多目标识图坐标、跨进程高级识图消息、窗口关闭与重新打开、
实际 MP4 编码解码以及编码器失败后继续预览。
另覆盖真实客户区 `950×596`、仅采样点为黑但其余内容可见、RGB 全黑但 Alpha 不透明的可用性判断。
预览覆盖 100%、125%、150%、200% 屏幕像素密度，验证清晰预览不会改变录像尺寸。

大厅画面来源另覆盖：三层句柄解析（Flash / CEF 内容层 / 360 外框）、内容层必须是本玩家外壳的子窗口、
DPI 不感知窗口的黑边裁剪、画布随实际绘制区域变化、录像宽高取偶数。
游戏客户区的画布与录像仍是固定 `950×760`。
调试用的“模拟识别事件”覆盖：无观测句柄时也能注入、开关关闭时不注入、事件按时间过期、
命中框出现在真实合成帧上、没有可用截图时仍能画在画布上。

`output/preview.png` 为合成示意图，`output/window.png` 为工具窗口示意图，不是真实游戏截图。
测试录像写入 `output/` 的临时子目录，读取校验后自动清理。

## 真实游戏验收

1. 在 FAA 保存玩家窗口设置，进入游戏，点击进阶设置左侧“实用小工具”和“更多工具”之间的“FAA视角”。
2. 不点录制，确认画面持续刷新；分别切换 1P/2P，确认选中正确客户区。
3. 未进入游戏时把“画面来源”切到大厅内容层、大厅外框，确认能看到选服页和 360 工具栏，右侧与下方没有黑边。
4. FAA 执行登录或选服时检查大厅层的黄色点击动画及绿色识图框；切回游戏客户区后检查战斗中的点击与识图特效。
5. 分别关闭、开启两种特效，确认只影响显示，不影响 FAA 实际识图结论。
6. 在没有真实识图发生的阶段勾选“模拟识别事件”，确认出现绿框（带名称与匹配度）、底部未命中调试行和黄色点击圈；
   关掉游戏窗口或让截图不可用时也应继续显示，取消勾选后立即停止。
7. 开始录制，确认玩家与画面来源锁定。停止录制后预览应继续，MP4 应包含当时开启的特效。
8. 录制中调整大厅窗口大小，确认录像分辨率不变且画面等比缩放补黑边。
9. 录制中关闭工具或退出 FAA，确认录像仍可播放。重新打开工具应重新采集。
10. 游戏刷新或暂时丢失窗口时应显示等待提示，重新进入游戏后恢复预览；不应显示另一玩家的窗口。
